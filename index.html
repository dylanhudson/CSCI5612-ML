Home

Hello! Welcome to my website for my machine learning project coursework for CSCI 5612 at CU Boulder. This project covers applications of various ML algorithms to cancer data, investigating various predictive features including demographics, lifestyle, and genomics. The project is organized into sections covering data preparation/EDA, clustering, association rule mining, decision trees, naive Bayes, support vector machines, regression, and neural networks. The goal is to demonstrate application of machine learning techniques to cancer data and to gain insights into the factors influencing cancer outcomes and occurrence. More information can be found using the nav bar on the left to explore specific sections.
