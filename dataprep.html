Data Preparation and EDA

This table organizes the various datasets sourced for the project, with links to the host sites/APIs, descriptions, and respective pages with EDA and cleaning processes.

Dataset Description Source EDA/Cleaning Data & Code
Clinical Case Data from the NIH Proteomic Data Commons (PDC) Patient-level demographic, risk factor, and protein expression data. Pulled by API PDC API script, EDA/Cleaning Github
500 Cities Health Data Health-related data for 500 US cities, including lifestyle factors and health outcomes. CDC 500 Cities 500 Cities EDA/Cleaning Github
Genomic Data from TCGA Genomic and clinical data for various cancer types from The Cancer Genome Atlas. TCGA Data TCGA EDA/Cleaning Github
Synthetic Pancreatic Cancer Data 2,000 pt simulated dataset with cancer subtypes, genetic mutations, treatment modes, and other clinical features Kaggle EDA/Cleaning Github
NIH PubMed Abstracts Abstracts from PubMed related to certain cancer prognoses for qualitative use or NLP. Pulled by API. PubMed API script, EDA/Cleaning Github
EPA Annual Air Quality Data Data on air quality and environmental factors from the Environmental Protection Agency (EPA). EPA Data EDA/Cleaning Github
USGS Pesticide Use Data Data on pesticide use from the United States Geological Survey (USGS). USGS Data EDA/Cleaning Github
National Cancer Institute State Cancer Profiles Data on cancer incidence and mortality rates by state from the National Cancer Institute. NCI Data EDA/Cleaning Github
USDA Economic Research Service Data Reports on unemployment and education levels USDA Data EDA/Cleaning Github
