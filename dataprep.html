Data Preparation and EDA

This table organizes the various datasets sourced for the project, with links to the host sites/APIs, descriptions, and respective pages with EDA and cleaning processes. Below is an image gallery, with thumbnails and links for raw and cleaned data examples, as well as visualizations from the EDA process (these are also shown in the Jupyter notebooks linked in the first table.) Some raw and cleaned data was too large to upload to Github, so larger files are hosted here on Google Drive.

Dataset Description Source EDA/Cleaning (HTML Jupyter Notebook) Data & Code
Clinical Case Data from the NIH Proteomic Data Commons (PDC) Patient-level demographic, risk factor, and protein expression data. Pulled by API PDC API Calls and Parsing/Cleaning Notebook. First, the available fields from the respective APIs were determined, i.e. demographic fields, case IDs, etc. Then, the data was pulled from each API endpoint and combined in a single dataset, mapping cases to aliquots (protein profiles). Then, "days_to_birth" columns was converted to age in "years. Then, the data was subset according to particular fields, e.g. whether smoking data was present, so NaNs could be dropped from each subset without affecting others for which the missing data may not affect the analysis. The cleaned data was exported. Github
500 Cities Health Data Health-related data for 500 US cities, including lifestyle factors and health outcomes. CDC 500 Cities 500 Cities EDA/Cleaning Notebook. The data was read in as a csv. Then rows with NaN values were dropped. Then, the US Census Geolookup API was used to convert location coordinates to county FIPS codes. Then, some columns were renamed for easier coding, and the dataset was subset to only relevant columns. Github
Genomic Data from TCGA Genomic and clinical data for various cancer types from The Cancer Genome Atlas. TCGA Data TCGA EDA/Cleaning Notebook. First, the data was read in as a csv. Then, columns with high NaN counts, and those irrelvant to the analysis were dropped. Github
Synthetic Pancreatic Cancer Data 2,000 pt simulated dataset with cancer subtypes, genetic mutations, treatment modes, and other clinical features. Kaggle EDA/Cleaning Notebook. This synthetic data was created for ML purposes, so it was already quite clean. A few columns had high NaN counts, so those were dropped. No further cleaning was immediately necessary, so some EDA and visualization was conducted. Github
NIH PubMed Abstracts Abstracts from PubMed related to certain cancer prognoses for qualitative use or NLP. Pulled by API. Example of the API call and reponse: PubMed API Calls/Parsing, Data Export Notebook. The data was pulled using the PubMed API. As this data is mostly unstrucured, it is primarily for potential NLP use if applicable. Key points like Title and Background were parsed out via regex to test feasibility of structuring if needed later. Github
EPA Annual Air Quality Data Data on air quality and environmental factors from the Environmental Protection Agency (EPA). EPA Data Cleaning and EDA Notebook. The data was read in as a csv. The State and County codes were convered to FIPS codes using a lookup table from the US Census. Columns with high numbers of missing data were dropped, along with irrelevent administrative data. Then, NaN rows were dropped. Github
USGS Pesticide Use Data Data on pesticide use from the United States Geological Survey (USGS). USGS Data Cleaning and EDA Notebook. The data was first read in as a TSV file. Then the state and county FIPS codes were combined to match the other datasets' 5-digit FIPS code. Pesticide level estimates were converted to numeric. Columns iwht over 80% NaNs were dropped; many have many NaNs, but it is not decided yet which pesticides are relevant for later analysis. Github
National Cancer Institute State Cancer Profiles Data on cancer incidence and mortality rates by state from the National Cancer Institute. NCI Data Cleaning and EDA Notebook. The data was read in as a csv. Columns with special chars in the names were renamed, and numeric columns were coerced to floats. Github
USDA Economic Research Service Data Reports on unemployment and education levels USDA Data Cleaning and EDA Notebook. The data was read in as a csv. The FIPS codes were observed to be slightly malformatted, so those were fixed. The data was subset to factors that are tractable for comparative anlaysis, i.e. those with percentages instead of raw numbers. The data was pivoted from long-form to create a dataframe with each of the factors as columns. To deal with the large amoutn of missing data at the per-year resolution, the data was aggregated to decades, then subset to just the 2000s to better match the time frames of the other datasets. Github
